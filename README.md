# MagCharge Sales SaaS

AI-powered sales and business management platform for MagCharge.

## Core Modules

- Sales
- Inventory
- Customers
- Orders
- Payments
- Dealers
- Warranty / RMA
- Analytics
- Admin
- AI Command Center
  - ChatGPT Assistant
  - BALMZ AI

## Architecture

- Web application
- API service
- Database
- Authentication and role-based access control
- Controlled AI tool/API layer
- Audit logging

## Project Separation

This SaaS is a separate project from the MagCharge hardware repository.

Hardware repository:
`PWFB-Magnetic-Charge`

SaaS repository:
`magcharge-sales-saas`
